Claude profiles
Claude conversations use one profile at a time: the first usable one in the priority (the numbers; change it with the arrows). When the one in use reaches its 5-hour or weekly limit, its reset time is recorded and new and continued conversations move to the next usable profile, and back once one ahead of it can be used again; Claude waits only while every profile is at its limit, and starts again by itself at the first reset. Only ticked profiles are in the rotation: untick one to keep it for other use, and it is never switched to; if it is the one in use, conversations move to the next ticked one at once. A conversation is stored once, whichever profile runs it. Usage is what Claude Code reported when a window's state last changed (within its limit, approaching it, at it); Anthropic reports nothing in between. To sign a profile in, run CLAUDE_CONFIG_DIR=<its directory> claude on the Linux host, then /login with that subscription account.

Codex profiles
Codex conversations, the workers', reviewers', the Integrator's and the Dispatcher's, use one account profile at a time: the first usable one in the priority (the numbers; change it with the arrows). When the one in use reaches a usage limit, its reset time is recorded and new and continued conversations move to the next usable profile, and back once one ahead of it can be used again; Codex waits only while every profile is at its limit, and starts again by itself at the first reset. Only ticked profiles are in the rotation: untick one to keep it for other use, and it is never switched to; if it is the one in use, conversations move to the next ticked one at once. A conversation is stored once, whichever profile runs it. Usage is what Codex last reported for each window during a conversation. To sign a profile in, run CODEX_HOME=<its directory> codex login --device-auth on the Linux host with the pinned Codex, and sign in with that ChatGPT account; sign each profile in to a different account.

Run controls
Pause after turn lets the turns in progress finish on their own and starts nothing after them, for a group's members old and new. Resume lets a group run, its own work, new tasks and new members included, also while everyone else is paused. A person paused or resumed on their own keeps that. The Integrator and the Dispatcher follow Everyone, and Pause all or Resume all ends every group's control.
